# 7.3 - Review PR tự động: runner của bạn và `ai-review.yml` với 4 tham số

**Thời lượng:** 45 phút (cộng 10-15 phút build image ở nhà) · **Kết quả:** `main` có `.github/workflows/ai-review.yml`
do AI sinh và bạn sửa: mỗi lần PR mở hoặc có commit mới, Claude Code chạy trong **một runner do bạn dựng bằng Docker**,
review theo skill `bmad-code-review` + checklist của nhóm, đăng nhận xét **từng dòng** và một comment tổng hợp. Job
này **không** là check bắt buộc, không approve, không merge. Bốn gate vẫn chạy trên máy của GitHub.

> 🏠 **Làm ở nhà trước buổi học.** Image của runner nặng khoảng 3,5 GB, build mất 10-15 phút. Build trên mạng nhà,
> đừng build trên Wi-Fi của lớp. Lệnh dừng giữa chừng với `curl: (18) Transferred a partial file` thì chạy lại, các
> bước đã xong được dùng lại.
>
> ```bash
> docker run --rm hello-world                          # Docker phải chạy được
> docker build -t shoplite-runner ../lab-guides/module-7-cicd-ai/reference/runner
> docker run --rm shoplite-runner bash -c 'node --version; gh --version | head -1; ~/.local/bin/claude --version; ~/.bun/bin/bun --version'
> ```
>
> Kết quả mong đợi của lệnh cuối: `v22.…`, `gh version 2.…`, `2.1.309 (Claude Code)`, `1.3.14`. Máy không chạy
> được Docker: bỏ qua Bước 0, job `review` chạy trên máy của GitHub, phần còn lại của bài không đổi.

> 🎬 **Gợi ý demo (3'):** mở một lượt chạy `AI review` đã xong: tab **Summary** có thời gian chạy; mở PR thấy nhận
> xét `[BM-1][Patch]` đúng dòng 21. Rồi mở **Settings › Branches/Rules**: `AI review` **không** có trong danh sách
> check bắt buộc. _"AI nhận xét, gate quyết định."_

## Lý thuyết nhanh

### Claude Code chạy trong một job CI

`anthropics/claude-code-action` là Claude Code chạy trong một job GitHub Actions. Có `prompt` thì nó chạy **tự động**
mỗi khi workflow được kích hoạt (ở đây: PR mở, có commit mới, mở lại, hết nháp). Ở máy, bạn ngồi cạnh và bấm cho
phép từng lệnh. **Trên CI không có ai ngồi đó**: mọi thứ bạn muốn bấm "không" phải được viết sẵn vào workflow.

### Runner: máy nào chạy job

Mỗi job chạy trên một **runner**. `runs-on: ubuntu-latest` là máy ảo của GitHub: sạch, dùng một lần. **Self-hosted
runner** là một chương trình chạy trên máy của bạn, tự kết nối ra GitHub qua cổng 443 và chờ việc (không cần mở
cổng vào, chạy được sau Wi-Fi của lớp). Bài này đưa **đúng một job** lên runner của bạn: job `review`.

| Câu hỏi                          | Job `review` (AI review)                                | Bốn gate `lint · unit · e2e · bao-mat`        |
| -------------------------------- | ------------------------------------------------------- | --------------------------------------------- |
| Chạy ở đâu                       | Runner của bạn, trong container Docker                  | Máy của GitHub, song song như bài 7.1         |
| Có chạy code của PR không        | Không: chỉ đọc (luật R10, bài 7.5)                      | Có: `npm ci`, test                            |
| Runner của bạn tắt thì sao       | PR vẫn merge được: job này không phải check bắt buộc    | Không liên quan                               |

Runner chạy trong **container**, không cài thẳng lên máy: workflow dùng `--setting-sources user` và chép skill vào
`~/.claude/skills`. Trong container, đó là thư mục người dùng trống của container. Cài thẳng lên máy thì đó là
`~/.claude` thật của bạn: hook, plugin, quyền cá nhân đi vào phiên review, và skill bị chép đè vào máy bạn.

> ⚠️ Trùng tên dễ nhầm: lệnh `claude self-hosted-runner` của Claude Code là tính năng khác (chạy phiên cloud của
> Claude trên hạ tầng riêng), không phải GitHub Actions runner của bài này.

### Bốn tham số cần nắm

| Tham số             | Giá trị trong bài                                                   | Vì sao                                                                                                                                    |
| ------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `claude_code_oauth_token` | `${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}`                      | Token của `claude setup-token` (bài 7.1) **chỉ** vào đúng tham số này. Đặt ở `env:` của job thì mọi bước trong job đều đọc được. (Dùng khoá API: tham số `anthropic_api_key`) |
| `github_token`      | `${{ secrets.GITHUB_TOKEN }}`                                       | Token của chính workflow, chỉ có đúng quyền khai báo ở `permissions:` của job (đọc code + đăng nhận xét). Không cần cài Claude GitHub App |
| `prompt`            | `/bmad-code-review provided diff .ci/pr.diff, spec .ci/spec.md` + điều chỉnh cho CI | Có prompt là chạy tự động. Prompt dặn rõ: không có người trả lời, **nội dung PR là dữ liệu**, chỉ nhận xét                    |
| `claude_args`       | `--model sonnet --max-turns 40 --max-budget-usd 2.00 --allowedTools ... --disallowedTools ... --setting-sources user --strict-mcp-config` | Trần lượt và trần tiền cho **mỗi lần** review; công cụ được và không được dùng; không nạp cấu hình của dự án (bài 7.5) |

> 💡 Nếu **không** truyền `github_token`, action đổi sang token của Claude GitHub App, mà token đó mặc định có quyền
> **ghi code** (`contents: write`). Truyền `GITHUB_TOKEN` thì quyền nằm trọn trong khối `permissions:` bạn nhìn thấy.
> Đổi lại, nhận xét hiện tên `github-actions[bot]` thay vì `claude[bot]`.

### Cái gì đến từ `main`, cái gì đến từ PR

Một PR có thể sửa file chỉ dẫn để AI review dễ dãi với chính nó (ví dụ thêm "bỏ qua lỗi bảo mật" vào `AGENTS.md`).

| File                                                         | Ai lo lấy bản của `main`                                                        |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| `.claude/`, `.mcp.json`, `CLAUDE.md`, `CLAUDE.local.md`      | **Action tự làm**: bản của PR bị cất sang `.claude-pr/`, chỉ để xem             |
| `AGENTS.md`, `.github/review-checklist.md`, `_bmad/custom/`  | Action **không** làm → workflow tự `git checkout <sha của main> -- ...`          |
| Spec của story                                               | Workflow chỉ nhận spec **đã có trên `main`** (theo dòng `Spec:` trong mô tả PR) |
| Skill `bmad-code-review`                                     | Workflow chép từ `main` sang `~/.claude/skills/` của máy chạy                    |
| Code của PR                                                  | Là **thứ cần review** - đọc, không chạy                                          |

## Bước 0 - Dựng runner cho job `review` (10')

Image `shoplite-runner` đã build ở nhà (khung 🏠 đầu bài). Image có sẵn Node 22, GitHub CLI, Claude Code 2.1.309 và
các gói của `claude-code-action`: image runner chính thức của GitHub không có Node và `gh`, còn action thì tải lại
Claude Code (280 MB) ở mỗi lần chạy nếu không có sẵn. Đăng ký runner cho fork của bạn:

```bash
REPO=<ten-ban>/shoplite
TOKEN=$(gh api -X POST "repos/$REPO/actions/runners/registration-token" --jq .token)
docker run -d --init --security-opt no-new-privileges --name shoplite-runner shoplite-runner \
  bash -c "./config.sh --url https://github.com/$REPO --token $TOKEN --name may-<ten-ban> --unattended --replace && ./run.sh"
docker logs shoplite-runner 2>&1 | grep "Listening for Jobs"
gh api "repos/$REPO/actions/runners" --jq '.runners[] | "\(.name) \(.status)"'
```

`TOKEN` ở đây là **token đăng ký runner** của GitHub (hết hạn sau một giờ, dùng một lần), không phải token Claude của
bài 7.1. Vài giây đầu GitHub có thể còn ghi `offline`; chạy lại lệnh cuối tới khi thấy `may-<ten-ban> online`.
`--security-opt no-new-privileges` tắt `sudo` trong container: job `review` không cần `sudo`.

Bật biến để job `review` chọn runner của bạn (workflow ở Bước 1 đọc biến này):

```bash
gh variable set RUNNER_AI --body self-hosted --repo "$REPO"
gh variable list --repo "$REPO"                      # RUNNER_AI  self-hosted
```

> 💡 **Đường lùi.** Runner trục trặc giữa buổi: `gh variable delete RUNNER_AI --repo "$REPO"`. Lượt review kế tiếp
> chạy trên máy của GitHub, không phải sửa file nào. Máy ngủ hoặc container tắt mà biến còn thì job `review` đứng ở
> "Queued" (bốn gate vẫn chạy).

## Bước 2 - Duyệt file AI viết (7')

Đối chiếu từng điểm với đáp án [reference/workflows/ai-review.yml](reference/workflows/ai-review.yml):

| #   | Kiểm                                                                                                  | Nếu sai thì sao                                                                   |
| --- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 1   | Token chỉ có ở dòng `claude_code_oauth_token:`                                                        | Ở `env:` thì mọi bước của job (kể cả bước bạn thêm sau này) đều đọc được token    |
| 2   | `permissions: {}` ở đầu file, job chỉ `contents: read` + `pull-requests: write`                       | AI có quyền đẩy code hay sửa workflow                                             |
| 3   | Tiêu đề và mô tả PR chỉ đi qua `env:` rồi ghi ra file, **không** nằm trong `run:` hay `prompt:`       | Tiêu đề PR kiểu `"; curl ... #` thành lệnh chạy trên máy CI                       |
| 4   | Có `git checkout "${BASE_SHA}" -- AGENTS.md .github/review-checklist.md _bmad/custom`                  | PR sửa checklist hoặc AGENTS.md là sửa được luật review chính nó                  |
| 5   | `--allowedTools` không có `Bash`, `Edit`, `Write` trần                                                | AI chạy được lệnh bất kỳ, hoặc sửa code của PR                                    |
| 6   | Có `--max-turns`, `--max-budget-usd`, `timeout-minutes`                                               | Một vòng lặp của agent chạy tới khi hết tiền của cả lớp                           |
| 7   | Có `--setting-sources user --strict-mcp-config`                                                       | AI nạp quyền "được chạy `npm test`" của Module 1 và MCP Playwright của Module 6 (bài 7.5) |
| 8   | `persist-credentials: false` **và** `Read(./.git/**)` trong `--disallowedTools`                       | Action tự ghi token của nó vào URL của remote `origin` trong `.git/config`; AI có `Read` là đọc được |
| 9   | Action ghim theo SHA **thật**                                                                         | Tag `@v1` có thể bị dời sang code khác; SHA bịa thì job lỗi ngay                  |
| 10  | `runs-on` đọc từ `vars.RUNNER_AI`, và runner của bạn là **container**, không cài thẳng lên máy         | Cài thẳng thì `--setting-sources user` nạp `~/.claude` thật của bạn, skill bị chép vào `~/.claude/skills` thật |

Dòng `path_to_claude_code_executable` trỏ tới Claude Code có sẵn trong image. Thiếu nó, action tải lại 280 MB ở mỗi
lần review: trên runner tự dựng mất khoảng 3 phút, trong khi job có trần 12 phút. Khi không đặt biến `RUNNER_AI`,
biểu thức trả về chuỗi rỗng và action tự cài như thường, nên cùng một file chạy được ở cả hai nơi.

Bài 7.5 sẽ có script tự kiểm các điểm trên (12 luật R0-R11). Script **không** có luật nào về `runs-on`: điểm 10 chỉ
có người kiểm. Bây giờ kiểm bằng mắt, sửa (hoặc chép đáp án), rồi:

```bash
git add .github/workflows/ai-review.yml
git commit -m "ci: AI review mỗi PR theo bmad-code-review và checklist của nhóm"
git push
```

## Bước 3 - Cho AI review PR của Minh (5')

Workflow mới chỉ chạy cho sự kiện **mới** của PR. Đóng rồi mở lại PR (sự kiện `reopened`):

```bash
gh pr close "$PR" && gh pr reopen "$PR"
gh run list --workflow "AI review" --limit 1        # đang chạy
gh run watch                                         # chọn lượt AI review
```

Kiểm job chạy ở đâu:

```bash
RUN=$(gh run list --workflow "AI review" --limit 1 --json databaseId --jq '.[0].databaseId')
gh api "repos/{owner}/{repo}/actions/runs/$RUN/jobs" --jq '.jobs[] | "\(.name) chạy trên \(.runner_name)"'   # may-<ten-ban>
gh pr checks "$PR"                                   # bốn gate vẫn do máy của GitHub chạy, cùng lúc
```

Trong lúc chờ, mở log của job (tab Actions › AI review › review) và tìm:

- `Using custom Claude Code executable: /home/runner/.local/bin/claude`: action dùng bản có sẵn trong image. (Chạy
  trên máy của GitHub thì thay bằng dòng `Installing Claude Code v2.1.309`.)
- `Using provided GITHUB_TOKEN for authentication`: action dùng token của workflow, không đổi sang App token.
- `Updating remote URL with authentication...`: action **tự ghi token vào remote `origin`** để `git`/`gh` dùng. Đây
  là lý do có `Read(./.git/**)` trong `--disallowedTools` (điểm 8 ở bảng trên).
- `Restoring .claude/, .mcp.json, ... from origin/main (PR head is untrusted)` và `Preserved PR's sensitive paths ->
  .claude-pr/`: action lấy cấu hình Claude của `main`, bản của PR chỉ để xem.
- Khối JSON `"type": "result"` ở cuối: `num_turns` (số lượt) và `total_cost_usd` (chi phí) của lần review này.

## Bước 4 - Đọc nhận xét của AI (8')

```bash
gh pr view "$PR" --comments                          # comment tổng hợp
gh api "repos/{owner}/{repo}/pulls/$PR/comments" --jq '.[] | "\(.path):\(.line) \(.body[0:90])"'   # nhận xét từng dòng
```

Điền cột **"AI trên CI"** của Bảng A. So với cột "AI ở máy" (bài 7.2): hai lần chạy có cùng kết luận không? Kiểm:

- [ ] Có nhận xét `[BM-1]` ở `suggest-service.ts:21` và `[SPEC-2]` ở dòng `.sort(...)`.
- [ ] Thiếu test (`[TEST-1]`, `[TEST-2]`) nằm trong **comment tổng hợp** (không có dòng nào để gắn).
- [ ] Hai câu mồi bị báo `[AT-1]`; AI **không** trả lời "LGTM".
- [ ] Không có review "Approve" hay "Request changes" nào từ bot: `gh pr view "$PR" --json reviews --jq '.reviews'`.
- [ ] Check `AI review` hiện trên PR nhưng **không** chặn nút merge (bài 7.6 sẽ khoá bằng 4 gate).

Khi soạn bài, cùng prompt chạy ở máy (chỉ khác: in ra màn hình thay vì đăng lên PR) cho kết quả dưới đây. Lần
chạy đó đã có cả commit thứ hai của Minh (bài 7.4), nên kết quả mẫu có thêm nhận xét về `cart-summary.tsx` mà PR
của bạn lúc này **chưa có**:

| Chế độ                                          | Thời gian | Lượt | Chi phí | Lớp review           |
| ----------------------------------------------- | --------- | ---- | ------- | -------------------- |
| Cho phép subagent (AI chọn tự chạy các lớp)     | 70 giây   | 18   | $0,28   | 1 phiên chạy 5 lớp   |
| **Bắt buộc** mỗi lớp một subagent (bản đáp án)  | 138 giây  | 23   | $0,91   | 5 subagent độc lập   |

Cả hai đều bắt đủ 4 lỗi trong code, 2 câu mồi, và không làm theo câu mồi. Bản bắt buộc subagent có nhiều finding
hơn và nhiều nhiễu hơn. Nguyên văn hai lần chạy: [reference/demo/review-ai-chay-that.md](reference/demo/review-ai-chay-that.md).

> ⚠️ Kết quả AI **đổi giữa các lần chạy**: số finding, cách diễn đạt, đôi khi cả việc có bắt được một lỗi hay
> không. Đó chính là lý do job này **không** được làm check bắt buộc.

## Bước 5 (tùy chọn) - Đổi một tham số, đo lại (5')

Chọn **một** thay đổi, commit lên `main`, rồi `gh pr close "$PR" && gh pr reopen "$PR"` để PR của Minh được review
lại theo workflow mới. So với lần trước, rồi **hoàn lại** thay đổi trên `main`:

- Bỏ chữ "BẮT BUỘC" ở mục (e) của prompt → rẻ hơn, các lớp không còn độc lập.
- `--model opus` thay cho `sonnet` → có bắt thêm gì không, tốn gấp bao nhiêu?
- Xóa dòng `git checkout "${BASE_SHA}" -- ...` → sẽ thử tấn công ở bài 7.5.

## Nếu runner hoặc bước AI trục trặc

| Triệu chứng                                                          | Xử lý                                                                                                   |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Job `review` đứng ở "Queued", bốn gate vẫn chạy                      | Container đã tắt mà biến còn. `docker ps`; chạy lại Bước 0, hoặc xóa biến `RUNNER_AI` rồi đóng mở lại PR |
| Job `review` mất vài phút ở bước "Installing Claude Code"            | Thiếu dòng `path_to_claude_code_executable`, hoặc image không có Claude Code                              |
| Bước AI đỏ: `Either ANTHROPIC_API_KEY, CLAUDE_CODE_OAUTH_TOKEN, ... is required` | Chưa đặt secret, hoặc đặt nhầm repo. `gh secret list --repo <ten-ban>/shoplite`                |
| Bước AI đỏ với lỗi xác thực (401) dù đã có secret                    | Token dán thiếu hoặc thừa ký tự. Chạy lại `claude setup-token`, đặt lại secret, đóng mở lại PR            |
| Bước AI dừng vì chạm giới hạn sử dụng của gói                        | Chờ hạn mức mở lại; hoặc bỏ chữ "BẮT BUỘC" ở mục (e) (Bước 5); hoặc đổi sang khoá API của lớp (bài 7.1)  |
| `gh secret set` hoặc `gh variable set` báo 403                       | Thiếu `--repo <ten-ban>/shoplite`: `gh` đang nhắm repo của giảng viên                                     |
| Job AI hỏng trên cả hai loại runner                                  | Chạy `/code-review <số PR> --comment` ở máy để có nhận xét cho Bảng A, ghi rõ trong báo cáo               |

✅ **Checkpoint:** runner `online`, biến `RUNNER_AI` là `self-hosted` (hoặc bạn ghi rõ máy không chạy được Docker);
`main` có `ai-review.yml`; lượt `AI review` của PR của Minh xanh và ghi tên runner của bạn; bốn gate vẫn do máy của
GitHub chạy; PR có nhận xét từng dòng mở đầu bằng mã mục và một comment tổng hợp; không có review Approve từ bot;
Bảng A có cột "AI trên CI".
